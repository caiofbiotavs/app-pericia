Como usar o painel Admin

  1. Informe usuário e senha e clique em Login.
  2. Depois do login, você poderá importar um arquivo JSON ou apagar a cadeia local.
  3. Use Importar e gravar no navegador para substituir a cadeia atual.
  4. Use Apagar cadeia local somente se quiser reiniciar o processo no navegador.

Autenticação apenas no cliente (hash SHA-256 comparado a users.json). Não use como modelo de segurança em produção.
