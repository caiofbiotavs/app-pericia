Visão geral

Este manual é o guia operacional do App Perícia. Ele descreve os passos que um perito ou auditor deve seguir para registrar evidências, validar cadeias, gerar prova pública e administrar o sistema.

Sempre que uma funcionalidade for alterada, volte a esta página para confirmar o fluxo atualizado. Use o menu para navegar rapidamente entre as páginas do app.

Dashboard

  1. Abra o menu e clique em Dashboard.
  2. Preencha os campos de referência, processo/caso, descrição e hash do artefato.
  3. Clique em Adicionar bloco para incluir a evidência na cadeia local.
  4. Para gerar hash de um arquivo, use o campo de hash e clique em Gerar hash.
  5. Quando quiser salvar a cadeia, clique em Exportar cadeia e baixe o arquivo JSON.
  6. Para carregar uma cadeia existente, clique em Importar cadeia e escolha o arquivo JSON exportado.

O Dashboard mantém os dados no navegador usando localStorage. Se você fechar a aba, a cadeia continua disponível no mesmo navegador, a menos que seja apagada manualmente no Admin.

Validação

  1. Abra o menu e selecione Validação.
  2. Clique em Validar cadeia local para verificar os hashes e a sequência de blocos carregados.
  3. Para validar uma cadeia externa, use Importar arquivo e selecione o JSON exportado de outra máquina.
  4. Verifique o resultado exibido na página: se a cadeia estiver íntegra, a validação retorna com indicação de sucesso.

A validação recalcula todos os SHA-256 e compara cada hash com o bloco anterior. Isso garante que a cadeia não foi alterada depois de criada.

Verificação pública

  1. Abra o menu e clique em Verificação pública.
  2. Clique em Gerar token público para criar um código que representa a cadeia atual.
  3. Use o QR code para compartilhar o token ou copie o texto gerado.
  4. Para comparar uma prova recebida, cole o token e clique em Verificar token.

O token público é uma forma simples de confirmar a correspondência entre uma cadeia local e uma prova compartilhada. Ele não substitui a exportação JSON, mas ajuda em verificações rápidas.

Painel Admin

  1. Abra o menu e selecione Admin.
  2. Informe seu usuário e senha e clique em Login.
  3. Para limpar a cadeia local, clique em Limpar cadeia.
  4. Para importar um arquivo de cadeia, use Importar cadeia no painel Admin.

O painel Admin é uma ferramenta administrativa de demonstração. Não use as credenciais do `users.json` como um sistema de segurança de produção.

Publicação em IPFS / Pinata

  1. Copie `site/js/config.example.js` para `site/js/config.js`.
  2. Abra `site/js/config.js` e adicione seu JWT do Pinata.
  3. Mantenha `site/js/config.js` fora do repositório e nunca compartilhe o JWT publicamente.
  4. Use os botões de publicação da página correspondente para enviar a cadeia ou o relatório para o Pinata.

Em ambientes reais, prefira mover o token JWT para um backend seguro e não armazenar segredos diretamente no cliente.
