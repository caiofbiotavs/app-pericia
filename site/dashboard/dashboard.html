Como usar o Dashboard

  1. Preencha referência, processo/caso e descrição.
  2. Informe o hash do artefato ou gere-o em Gerador de hash de artefato.
  3. Clique em Incluir bloco para registrar a evidência na cadeia local.
  4. Use Exportar JSON para salvar a cadeia em outro dispositivo.

Os blocos ficam apenas no localStorage deste navegador. Use exportar para guardar blockchain.json e validar em outra máquina ou após importação.
