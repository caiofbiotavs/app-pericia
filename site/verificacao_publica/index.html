Como usar a Verificação pública

  1. Clique em Gerar token de prova para criar um token do estado atual da cadeia.
  2. Use o botão Copiar token ou o QR code para compartilhar a prova.
  3. Cole um token no campo de verificação e clique em Verificar token.

O token indica a integridade atual da cadeia local. Ele permite comparar se duas cadeias são iguais sem enviar todo o JSON.

Geração de token público

Gere um token que representa a cadeia atual de evidências. Este token pode ser compartilhado como prova pública e verificado novamente a partir de outro navegador.
