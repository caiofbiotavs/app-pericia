Como usar a Validação

  1. Clique em Validar armazenamento local para conferir a cadeia salva no navegador.
  2. Para validar um arquivo exportado, selecione o JSON e clique em Validar arquivo.
  3. Leia a mensagem exibida para saber se a cadeia é íntegra ou se há erros.

A validação recalcula cada hash e verifica os elos previousHash. Alterar manualmente o localStorage quebra a cadeia.
